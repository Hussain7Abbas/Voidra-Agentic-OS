# P04 verification report

Date: 2026-09-20  
Host: Apple M4, 24 GB RAM, Apple Silicon (`arm64`), macOS 26.5.2  
Scope: versioned skills/routines, local manual prompt assembly, clipboard handoff, and reviewed result import

## Outcome

P04 is complete. A workspace can create and version skills, pin those versions in Claude or Codex routines, compile and edit an exact locally assembled prompt, copy it only through an explicit action, retain Awaiting Result separately from completion, review returned file bytes, and apply them only within the routine's output grant. A scheduled-manual fixture prepares a user action without writing the clipboard or contacting a model provider.

## Required P04 scenario evidence

- The UI creates a skill and Claude routine without API keys, compiles a prompt, lets the user edit it, and copies the exact reviewed bytes. The resulting run remains `awaiting-result`.
- A routine duplicated for Codex retains its own client/model preference and original pinned skill version. Both routines survive a full Electron restart under the same workspace identity.
- Prompt fixtures include effective persona, root and child rules, Unicode content, selected private/shared notes, source revisions, and matching active memory. They exclude sibling rules, another workspace's registries, detached bases, and recognized secret shapes.
- Identical inputs yield identical prompt text. Later skill edits do not alter an existing routine/run snapshot; a newly created routine opts into the latest version.
- Oversized selected context is rejected visibly. Revoked shared context fails closed instead of being compiled from stale data.
- State tests reject Ready/Copy directly to Completed. Result review precedes completion; cancellation remains separate.
- Traversal and symlink escapes are rejected. Apply revalidates the canonical output grant and detects changes made after preview before using an atomic write.
- Scheduled preparation persists a `ready-to-copy` run while an isolated clipboard sentinel remains byte-for-byte unchanged.

## Clipboard and external-client boundary

Playwright uses the explicit in-memory E2E clipboard adapter, not the host clipboard. This proves the renderer-to-main copy contract and exact text without mutating a developer's clipboard. Production code routes the same explicit action to Electron's native clipboard API, but this phase did not automate a real macOS clipboard smoke or restore cycle.

No Claude/Codex login, model picker, paste, submission, or returned response was automated. The returned result is a local user-supplied fixture. Passing tests demonstrate Voidra's handoff boundary, not successful execution inside either commercial client.

## Scale and regression observations

The complete suite retains the provisional 10,000-note checks. After replacing a quadratic registry lookup with a path map and bounded file-read batches, the final full-gate private-corpus run measured 6,780 ms to launch/list 10,000 notes, 2,886 ms to construct the accessible graph, 60 ms search, 62 ms open, 33 ms editor response, and 610 MB aggregate Electron working set. These are single synthetic observations, not percentile budgets.

## Honest boundaries

- Secret redaction recognizes several common shapes but cannot prove arbitrary source text is safe. Exact prompt review remains mandatory.
- `draft` is reserved in the durable schema; current manual and scheduled compilation both become `ready-to-copy` because the complete prompt is already reviewable.
- Result import currently stages one text file per review. The run records the source manifest and applied path, but rich multi-file attachments and semantic diffs are future work.
- Model names are user-entered preferences. Voidra neither validates a live subscription catalog nor applies the selection in Claude or Codex.
- P07 still owns clocks, notifications, wake/sleep handling, and durable scheduling. P04 verifies only the scheduled-manual preparation contract.
