# P01 verification report

Date: 2026-09-20  
Host: Apple Silicon (`arm64`), macOS 26.5.2  
Scope: workspaces, settings, account references, and scoped instructions

## Outcome

P01 is complete. Work and Personal can be created in distinct roots, selected independently, restored after restart, and relocated without changing identity. Global settings and explicit workspace overrides report their origins. Root and nested instruction pairs resolve only along each target's ancestry. Account references remain workspace-bound and are not serialized back to the renderer.

No private knowledge, memory, conversations, browser sessions, or provider credentials are shared or implemented by this phase.

## Required scenario evidence

- Fresh launch creates Work, then Personal in another directory. Restart opens the saved default rather than silently following the last visible selection; the last route is restored separately.
- Ask on startup shows an explicit workspace launcher.
- Folder cancellation and duplicate registration create no second usable workspace.
- Global model/persona/voice values flow to Personal. Work's explicit model/persona/false voice values survive global changes, and removing its model override restores global inheritance.
- Scoped instructions create exact sibling pairs and resolve root plus child without sibling content.
- A delayed Work request returns Work ownership after the UI switches to Personal.
- A moved workspace is visibly unavailable until Locate Folder verifies the original manifest ID.
- Unwritable initialization is rejected. A simulated registry transaction failure leaves a recoverable, unregistered workspace rather than a partial registry row.
- Removing a registry entry leaves the workspace manifest and source directory intact.

## Honest boundaries

- The account layer proves scoped opaque references and renderer redaction, not live Keychain/provider authentication. Provider credential lifecycle remains later implementation work.
- Shared knowledge attachment and access modes begin in P03; P01 does not infer sharing from paths.
- Filesystem case behavior was exercised on the host's actual macOS volume; a separate case-sensitive volume matrix has not been run.
- GitHub Actions is authored but remote CI execution is not claimed by this local report.
