# P08 automated verification report

Date: 2026-09-20  
Host: Apple M4, 24 GB RAM, Apple Silicon (`arm64`), macOS 26.5.2  
Scope: workspace browser sessions, agent-assigned tabs, takeover/stale-document policy, downloads, crashes, and isolated HTML artifact bundles

## Outcome

P08 automated implementation is complete for the provisional built-in-browser choice. Workspace sessions and tab restoration are durable and isolated; OpenRouter tasks can operate one explicitly selected observable tab only through reviewed bounded actions; user takeover pauses the adapter; and interactive HTML/CSS/JavaScript artifacts run in separate, network-denied sessions with constrained asset routing and complete-bundle export.

Q05 remains unanswered, so this does not implement or reject a future explicitly paired Chrome mode. A human packaged-app browsing and preview smoke pass remains pending.

## Scenario evidence

- A real local HTTP site sets an HTTP-only Work cookie. Personal opens the same origin with no Work login. Restart restores the Work tab and its persistent partition cookie.
- A fixture download initiated in Work lands in `Work/Downloads/fixture.txt`; Personal has no corresponding file. Supplying the Work tab handle with Personal ownership is rejected.
- Agent type/read/click actions execute in the assigned real `WebContentsView`. Takeover blocks later actions until resume. A changed document rejects the stale document ID.
- A same-origin redirect succeeds, a cross-origin agent redirect is stopped, a popup is denied and recorded, and geolocation permission is denied by the real session handler.
- A local OpenRouter-shaped stream receives a `browser_action` tool only after its task owns the selected tab. The tool pauses for exact approval, executes through child-to-main correlated RPC, and returns the observed page result before completion.
- A reviewed form submission reports an uncertain effect, interrupts the task, and produces no second provider call or automatic replay.
- Force-crashing the browser renderer marks only its tab crashed. Reload creates a usable document while the main workspace UI stays responsive.
- An artifact loads relative CSS and JavaScript through the custom session protocol. Its button script runs, `window.voidra` is absent, external fetch is blocked by CSP, and encoded traversal returns no asset.
- Editing CSS with the expected revision reloads without cache. Export preserves HTML, CSS, and JavaScript. Direct traversal and a symbolic-link escape are rejected.

## Honest boundaries and pending acceptance

- The HTTP site and OpenRouter stream are local fixtures. Public websites, federated login, downloads that require OS quarantine interaction, and provider anti-automation behavior are not implied by these results.
- Browser pages and artifacts are actual Electron renderers, sessions, and protocol requests. Because `WebContentsView` is not a normal Playwright `Page`, content assertions use Electron main-process target discovery and bounded evaluation as documented in P00/P08.
- Permissions are denied by policy in this phase. Per-site grants have not been designed.
- Artifact network is denied provisionally. Per-artifact network controls remain a future design decision if a use case requires them.
- The generated application remains unsigned because no Developer ID identity is installed. Automated package smoke confirms launch, not a human browsing/preview interaction in the packaged binary.
