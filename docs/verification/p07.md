## Scenario evidence

- Time tests cover the New York spring gap and autumn duplicate, a leap date, next-day selection, timezone changes, invalid zones/windows/events, and daily next-occurrence calculation.
- Planner tests separate all-day/timed/recurring events, source IDs, due/overdue/optional tasks, overlaps, availability, unavailable integrations, and selected workspace knowledge. Stale plan saves fail.
- Real Electron creates and edits `Daily Plans/2026-09-20.md` with no API credential, prepares a manual handoff while a clipboard sentinel remains unchanged, and edits the default routine's preferred model.
- An OpenRouter-shaped fixture asks for the exact daily-plan file write; the task pauses for review, writes only after approval, and completes through the production automatic-task path.
- A real stdio MCP fixture advertises a calendar tool. Today previews exact changes and applies them only after separate approval. Repeating the same plan revision reuses its idempotency key and leaves one fixture event.
- Concurrent scheduler ticks claim one occurrence before dispatch. A reopened manager does not dispatch it again. Work and Personal schedules remain independent while the visible workspace switches.
- Skip, run-once, and review policies are covered. Manual occurrences become ready-to-copy and follow handoff status; automatic occurrences follow running, completed, cancelled, failed, and interrupted states.
- Disabling a schedule clears its next occurrence. Restart preserves the disabled schedule and prior occurrence history.
- Actionable scheduler events carry a stable notification key into Electron main. Manual preparation never invokes the clipboard adapter.
