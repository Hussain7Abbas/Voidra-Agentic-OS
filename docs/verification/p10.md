## Scenario evidence

- A partial transcript changes state but makes zero provider calls. Its final transcript creates exactly one OpenRouter task and one retained turn; replaying the same transcript ID is ignored.
- A deterministic Arabic transcript flows through the final task and selected workspace voice ID. This validates Unicode and routing only, not Iraqi Arabic quality.
- Real in-memory audio bytes are posted through multipart form data to the speech-to-text adapter. Synthesized bytes return to the renderer while the persisted registry contains no audio payload.
- “Interrupt” stops audio without necessarily cancelling reasoning. The distinct cancellation option aborts the owning automatic task and leaves the voice session interrupted.
- Switching from Work to Personal interrupts the Work voice session. Session handles cannot be used across workspace ownership boundaries.
- Speech authorization failure preserves the completed text response, retained caption, and explicit error state.
- Mute blocks transcript input and speech, transcript retention can be disabled and cleared, and deterministic wake activation obeys workspace configuration.

- The transcription adapter uploads after recording stops. Real-time partial transcription/reconnect behavior is not claimed.
- Production local wake recognition is not installed. Q10, an engine/license/package spike, target-language samples, false-positive/miss measurements, and idle CPU thresholds remain required.
- Live ElevenLabs credential, selected voice validation, actual playback, headset/echo behavior, network transitions, barge-in latency, and language/dialect acceptance remain required.
