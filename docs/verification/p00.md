# P00 verification report

Date: 2026-09-20  
Host: Apple Silicon (`arm64`), macOS 26.5.2  
Scope: architecture and test harness only

## Outcome

P00 is complete. The static Next.js export starts inside Electron without a development server; its validated preload reaches a supervised local service; a real SQLite database survives reopen; the Electron suite uses fresh profiles and real temporary folders; and an unsigned Apple Silicon directory package launches successfully.

This evidence does not claim signing/notarization, Intel compatibility, native permission dialogs, paid-provider behavior, or any later-phase product feature.

## Story evidence

- **P00-01:** Static routes and `/voidra-mark.svg` resolve under `app://voidra`; Electron relaunch restores the selected placeholder route; navigation uses semantic links and visible keyboard focus behavior.
- **P00-02:** UUID-bound requests are schema validated; responses preserve request correlation; the supervisor publishes state generations, bounds restarts, resolves pending failures, and exposes recovery in the shell.
- **P00-03:** Tests execute domain code outside Electron and use disposable on-disk SQLite databases. Fixture teardown closes handles and removes directories.
- **P00-04:** Playwright launches Electron against built output with a temporary user-data directory. Its folder stub feeds a real path through production canonicalization. Failure traces, screenshots, and video are retained when applicable.
- **P00-05:** Test/release differences and the version matrix are recorded in ADR 0001. The unsigned directory artifact has its own launch smoke rather than relying on the source-launched E2E suite.

## Known boundaries

- The application icon is still Electron's default; branding assets for packaging belong with release design work.
- The package is intentionally unsigned under the provisional personal-build assumption. Gatekeeper, signing, notarization, and installer checks remain P12 work after distribution decisions are confirmed.
- The P00 `WebContentsView` is an isolation/observability probe, not the P08 browser or artifact implementation.
- Electron's Playwright API remains experimental. The packaged smoke separately verifies the actual directory artifact, but native menu appearance and dialogs still require human macOS acceptance checks.
- GitHub Actions targets the official Apple Silicon `macos-15` hosted runner label. The workflow has been authored but was not executed locally as a remote CI run.
